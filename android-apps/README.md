# Aplicativos Android Harmony Car Wash

Este projeto gera dois aplicativos Android instaláveis:

- **Harmony Administrador** (`com.harmonycarwash.admin`): abre o painel administrativo completo.
- **Harmony André** (`com.harmonycarwash.andre`): abre somente o aplicativo operacional.

Os dois aplicativos se conectam a `https://watsappesimnovo.onrender.com` e precisam de internet. Fotos podem ser tiradas pela câmera ou escolhidas na galeria.

## Gerar no GitHub

Abra a aba **Actions**, escolha **Gerar aplicativos Android**, clique em **Run workflow** e aguarde a conclusão. Em **Artifacts**, baixe `Harmony-Android-APKs`, que contém os dois arquivos `.apk`.
